# オンライン対戦の同期テスト（手動で実行）

2つの独立したブラウザ（別々の匿名ログイン）で「対戦テスト」の部屋を作って対戦し、
両方の画面の盤面がそろっているか・操作が消えていないかを確かめます。

確かめている場面：
- 相手が対戦ログを開いている間に、手番側がオラクル（晴れ空の門出）を使う（マナ・墓地・天力）
- 自分を横にして招来するレガシー（麗しの狐姫）を出す（場に残るか）
- ターンを2回またいだあと、前のターンに出したレガシーが攻撃できるか
- 「相手が効果を選択中」が残りっぱなしにならないか

## 実行方法

本物の Firebase に「対戦テスト」の部屋を作ります（通常の対戦テストと同じく自動で消えます）。

1. このリポジトリの外の作業用フォルダで `npm i puppeteer-core` する（リポジトリには入れない）
2. `npm run preview` でローカルのサーバーを起動する
3. 作業用フォルダから `node <このフォルダ>/sync_test.js http://localhost:8765/index.html` を実行する
   （本番を確かめるときは URL を `https://tsukuriyo-online.netlify.app/` にする）

Chrome は `C:/Program Files/Google/Chrome/Application/chrome.exe` を使います。
最後に「結果：N/N 件OK」と出れば問題なし。NG の行に、食い違った盤面が出ます。
