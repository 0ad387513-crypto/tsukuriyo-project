# 演出設計室

ローカル確認用サーバーで `http://localhost:8765/kami_chibi_source/vfx_preview/tools/vfx-storyboard/` を開く。既存の創世神技確認ページからも移動できる。ツクリヨ本体へ自動反映する機能ではなく、演出の配置・時間・動きについて合意するための絵コンテ編集室。

使い方：①時間軸の時刻を選ぶ。②中央の画面で素材をドラッグする。③別の時刻で再度ドラッグする。◆の間を再生して確認する。左から素材を追加でき、素材の幅・高さ、各時刻での大きさ・角度・透明度、点と点のつなぎ方を右側で調整できる。羽衣の4つの形は画像欄で選べる。別の形をフェードで重ねたい場合は羽衣を複数置き、透明度を別々に指定する。

「設計データを保存」でJSONを出力し、「設計データを開く」で再編集できる。ブラウザーのローカル保存も行う。「指示文をコピー」は各素材の時刻・位置・透明度などを日本語で出力する。共有・実装時にはJSONが最も正確。座標は1280×720、左上(0,0)、中央(640,360)。

PNG/JPEG/WebPの持ち込み画像は1.9MB以下で読み込み、ブラウザー内と書き出すJSONに埋め込む。サーバーや本番には保存しない。読み込むJSONは形式・サイズ・画像URLを検証する。用意された画像と背景はプロジェクト内のファイルのみ。
