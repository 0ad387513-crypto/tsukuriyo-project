HはEの方向性を保ったまま、反射面・溝・唐草の陰影を少し深める。Iは銀の彫金を控えめに重ねる。新案の龍は黒い素材へ深紅を埋め込むグラデーション、縁の形に沿う赤い筋、鱗彫りと角を組み合わせる。中心は透明でカードの絵を描き変えない。基本・ユニーク・龍はE/H/Iの全9組について、今回修正前の素材描画と画素単位で一致することを確認。

カード上に種類名・種類アイコンは置かない。数値と既存の状態表示は残す。比較表の見出し・説明は外側に配置。同じ列は同じカード・切り抜き・数値を使う。Iの龍のみ淡い瘴気がゆっくり明滅。停止しても静的な形と色で区別する。

内側に属性色を残す。枠はネイティブSVGを重ねる方式（共有レンダラー `../../field_card_frames.js`）。大量の粒子、強い点滅、矩形のネオンは使わない。

## 確認用の切り替え

同じ赤属性／複数属性／レリック、対戦サイズ（高さ17.5vh）／145%／220%（彫りの詳細）／75%、通常／タップ中／行動可能／効果無効、動きON/OFF、白黒表示。下部は7枚が混在した場の例。水色の行動可能表示は種類の装飾と区別するための比較用であり、現行ゲームの行動可能表示を変更したものではない。

## 素材・分類

新規ラスター画像は生成せず、既存 `card_images/600/*.webp` と `field_card_art.js` の切り抜きを再利用。WebP URLには内容のSHA256先頭12桁を付与。カード情報は検証済み198カードのローカルスナップショット（`output/cpu-second-20261018/data.json`）から必要な11枚だけ抽出した静的な比較用データ。

分類はトークン→龍→創属性→同名カードの収録数で基本／ユニーク（現行 `cardPickKind` と同じ基準）を想定。龍のトークンはトークン優先。創属性のディエスイレは龍枠＋創の属性色。オラクルは場に残らないため対象外。
