# カード編集室（ローカル専用）

カードジェネレーター（ver3.3）をツクリヨのリポジトリに取り込んだものです。
カードのテキストをスプレッドシートに保存し、カード画像を描いて **ゲーム用のWebP（幅600・320）に自動圧縮して `card_images/` / `kami_card_images/` へ保存** します。

本番サイト（Netlify）では `/tools/` を公開しません（`_redirects` で404）。保存口はローカル確認用サーバーにしかないため、本番から編集されることはありません。

## 使い方

1. ツクリヨのフォルダで確認用サーバーを起動する

   ```
   npm run preview
   ```

2. ブラウザ（Chrome / Edge）で http://localhost:8765/tools/card-editor/ を開く
3. 画面上部の帯が緑なら、ゲームへ反映できる状態です
4. テンプレートからカードを読み込み、編集して **「シートとゲームに反映」** を押す
   - スプレッドシートのテキストが更新される（全プレイヤーに即時反映）
   - カード画像が `card_images/600/NNN.webp`・`card_images/320/NNN.webp` に保存される
   - 確認用サーバーのゲームを再読み込みすると、すぐに確認できる
5. 本番に出すときは、変更した画像をコミットして main に push する（Netlify が1〜2分で公開）

一括生成は「一括生成してゲームに反映」で、ZIPを作らずに直接ゲームの画像フォルダへ保存できます。

## イラスト（art/）

カードのイラストは `tools/card-editor/art/NNN.webp`（正方形・最大1170px・WebP）としてリポジトリに保存します。メンバー全員が同じイラストでカードを作り直せます。

- **テンプレートを選ぶと、保存済みイラストが自動でカードに載ります**（テキストだけ直すときにイラストを読み込み直す必要はありません）
- 新しいイラストは、読み込んで「カードに反映」→「シートとゲームに反映」で art/ にも保存されます
- 手元の「001_カード名.png」形式のフォルダは、「フォルダを選択」→「選んだフォルダのイラストを取り込む」でまとめて取り込めます（「一括生成してゲームに反映」でも、使ったイラストは art/ に保存されます）
- フレームや共通デザインを変えたときは「保存済みイラストで全カードを作り直す」で、全カードの画像を今のシートの内容で作り直せます
- リポジトリは公開なので、art/ のイラストも GitHub 上で誰でも見られます（本番サイトの /tools/ は404）

## 初回の準備

- **フォント**：有澤楷書・IPAex楷書など、カードに使うフォントを各自のPCにインストールしてください（フォントファイルはライセンスの都合でリポジトリに入れていません）
- **シートへの保存**：`config.example.json` を `config.local.json` にコピーし、GASのURLと合言葉を入れてください。合言葉はメンバー間で直接渡してください（コミットしない）
- GASの設定は `gas_setup.js` の先頭のコメントを参照

## 注意

- 新しい番号のカードを追加したときは、`index.html` の `LOCAL_CARD_IMAGE_MAX_NO`（カミは `LOCAL_KAMI_CARD_IMAGE_MAX_NO`）をその番号以上に上げてください。保存時に警告が出ます
- カードの「動き」（`effect_spec.json`）はこの画面ではまだ編集できません
- フレーム画像を追加・変更したときは `フレーム画像更新.bat` で `frames.js` を作り直します
