## 確認済みの内容

- 全6点：512×512px、アルファ透過あり、四隅と外周の余白は透明。
- 視認できる絵柄の外側に最低52px（約10%）の余白。横長・縦長の絵柄は形を保つため他方向の余白が広くなります。
- `preview.png` で暗い背景・明るい背景、20px・24pxの縮小表示を確認済み。実際のゲーム画面への組み込み確認は未実施です。
- 表示枠24pxに対して絵柄の最大辺は約19pxです。横に文字ラベルを残して使ってください。
- `validation.json` に寸法・透過・余白の計測結果を保存しています。

## Claude Codeへの引き継ぎ

これはPNG素材の納品です。ゲームのコード、参照URL、バージョンは変更していません。工具は動作確認用の項目を残す場合のみ使ってください。

実装時はプロジェクトのAGENTS.mdに従い、PNGを直接参照せず、`scripts/import_visual_asset.py` の `sprite` プロファイルでWebPへ圧縮し、出力されたハッシュ付きURLを使用してください。背景の透過は維持してください。圧縮・組み込み時に `version.js` を更新し、指定のテストとローカル確認用URLで検証してください。

## 生成履歴

OpenAIの組み込み画像生成ツール（built-in image_gen）で各アイコンを個別生成しました。最初に生成した本を残り5点の画風参照にしています。生成後はアルファを維持したまま、絵柄の位置・余白と出力寸法を機械的に整えました。

`prompts.json` に6点の最終生成プロンプトと生成元のパスを保存しています。`originals/` に生成時の原寸PNGを保管しています。戦績は四隅が丸まった旧版から、上下に横長の巻き芯がある改訂版へ差し替えました。ZIPには改訂版を含む納品用PNG6点・更新済みプレビュー・本書・プロンプト・検証結果を収録しています。
