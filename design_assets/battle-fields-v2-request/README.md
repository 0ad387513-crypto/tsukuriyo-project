## 今の背景の問題（作り直す理由）

ユーザーの評価は「AIで適当に出したのが丸わかりで、クオリティが低い」。具体的には次のとおりです。

1. **どの舞台にも同じ小道具が並ぶ**：鳥居・石灯籠・しめ縄・のぼり・満月が、忍者の里・森・沼・龍の台地にまで出てくる。「和風のものを全部入れた」ように見え、舞台ごとの個性が薄い。
2. **意味のない描き込みが多い**：家紋のような模様、読めない文字の旗、用途の分からない箱や布。画面の隅々まで同じ細かさで描かれ、見せ場がない。
3. **意匠がちぐはぐ**：神使の神殿は、教会のバラ窓と鳥居が脈絡なく並んでいる。龍の足跡は葉っぱの形に見える。
4. **CGっぽい光沢**：濡れた床の鏡のような映り込み、強い逆光、HDRのような明暗。対戦画面の飾り（黒漆に細い金線の控えめな蒔絵）と画風がまったく合わない。
5. **一点透視の奥行き**：地面が手前から奥へ強く伸びるので、平らに並ぶカードや窓とぶつかる。

## 新しい方向：黒地の屏風絵

対戦画面の飾りは「黒漆に細い金線、平らな塗り、広い余白」でそろえている。背景もこれに合わせ、**夜の屏風絵**として描いてもらう。

- 黒〜藍の地に、墨のにじみと岩絵具の落ち着いた色（緑青・群青・朱・黄土）を少しだけ。
- 金雲は使わない（試作の初版で「使い回しに見える・金が浮く」となったため）。外周は、その舞台に元からあるもの（竹の葉・梁・枝・洞窟の天井・煙など）を暗く沈めて縁取る。金は建物の金箔や細い輪郭線など、絵の中で自然な所だけ。
- 視点は高い位置から見下ろす（屋内は屋根を取り払って上から見る「吹抜屋台」）。遠近は弱く、平らな層を重ねる。
- 舞台ごとに、その種族だけの見せ場を1〜2個に絞る。鳥居・満月・灯籠は、その舞台に必要なときだけ。
- アニメ調・写実・3D・光沢・強い逆光は使わない。

## 画面の中での見え方（制約）

- 画面いっぱい（16:9）に敷く。ゲーム側で明るさ72%・彩度80%に落とし、外周をさらに暗くしてから表示する。
- `reference/layout-guide.png` の緑の範囲（横の中央62%・縦の29〜70%）に、カード（レガシー）が2段で並ぶ。ここは**細部と明暗差を小さく**し、地面・霞・水面など広い面にする。
- 上の中央と下の中央にカミの窓、右の端に渾天儀（ターンとマナの表示）、四隅にボタン・手札・山札などが重なる。ここも細かい見せ場を置かない。
- 見せ場にしてよいのは、左の端と、上の奥（画面の上の帯）。
- 中央を上下に分ける線（川・道・壁の縁など）は作らない。カードの2段のあいだに境目が見えると、ユーザーの指定（境目なし）に反する。
- 彼岸花は作品内で特別な意味があるため描かない（`battle_fields/README.md` のルール）。
