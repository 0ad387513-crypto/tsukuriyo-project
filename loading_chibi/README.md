# ロード画面のちびキャラ差分

組み込み ImageGen で、各カミの既存ちびキャラを外見の参考として生成。ヤマタノオロチは対象外。制作指示は「元の髪・目・装束・装飾を保ちつつ、背景透過の正方形ちびキャラを、休息や気晴らしの一場面として少しコミカルに描く」。各柱の場面は以下のとおり。

| カミ | 場面 |
| --- | --- |
| スサノオ | 大口を開けて大きなおにぎりを豪快に食べる |
| ヤマトタケル | 一人で盆栽の手入れをする後ろ姿 |
| オオクニヌシ | 白兎に団子を全部食べられ、空の串の盆を前に両手を広げる。周囲の獣は霊体 |
| タケミカヅチ | 木人を相手に汗をかきながら修行する |
| オモイカネ | 崩れた巻物の山の一番下から、筆を握って這い出す |
| アメノウズメ | 目が描かれたアイマスクをして熟睡する |
| ヒノカグツチ | 小さな炎で餅を焼く。角は一本 |
| アマテラス | お茶と和菓子を楽しむ |
| ツクヨミ | ユーザー指定画像を採用。虚空を見つめ、口を開けたまま全力でぼんやりする |

採用画像は `scripts/import_visual_asset.py` の `sprite` プロファイルで120KB以下のWebPに圧縮。起動直後と素材読み込み時のロード画面に、9柱からランダムに1柱とルールのヒントを表示する。`preview.html` で9柱を一覧で確認できる。`candidates/` は採用前の原画・比較用画像。
