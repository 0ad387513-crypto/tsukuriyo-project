# カミのちびキャラ

チュートリアルの `tutorial_guide/amaterasu-chibi.webp` を画風の基準にし、各カミの既存イラストを外見の参考にして、内蔵画像生成ツールで9柱を作成。

- 配信用：このフォルダーの透過WebP。全身を切り抜いた画像で、長辺768px。
- 元画像：`../kami_chibi_source/` の透過PNG。生成時の解像度で保存し、配信対象には含めない。
- 作成に使用した説明文と参照画像：`prompts.json`。
- プレイガイド：スサノオ、ヤマトタケル、オオクニヌシ、タケミカヅチ、オモイカネ、アメノウズメ、ヒノカグツチ、ツクヨミの8柱を追加。アマテラスは既存のちびキャラを使用。
- ヤマタノオロチ：`yamata-no-orochi-chibi.webp`。プレイガイドでは通常「？」で隠し、クリック後の警告に「はい」を選んだ場合だけ画像・名前・理念と専用ルールを表示する。ガイドを閉じると再び隠す。

ポーズは元のカードイラストから変更している。プレイガイドでは全身を収める表示と遅延読み込みを使用。

各章の見出し横にも、9柱の絵を挿絵として配置。本文や説明図には重ねず、画面の幅に合わせてサイズを変更する。ヤマタノオロチはこの挿絵には使用しない。
