# 対戦フィールド背景

星戦画面の背景です。2026-10 に、人物のいない「夜の屏風絵」（黒〜藍の地に墨と岩絵具、金は建物の金箔など絵の中で自然な所だけ）として6枚を作り直しました。
依頼の経緯・画風の決まり・画面の制約は `design_assets/battle-fields-v2-request/`、生成した原画と生成指示は `design_assets/battle-fields-v2/` にあります。

画面では内容ハッシュ付きの WebP（1600×900、`optimized_assets.json` に記録）を使います。ファイル名は `index.html` の `BATTLE_FIELD_THEMES` が参照します。
新配置（battleLayoutV2）では明るさ105%・彩度90%で敷き、外周だけを暗くします（絵はもともと暗めに描いてあるため、明るさは落とさない）。
旧 SVG は保管用に残していますが、画面では使用しません。

| --- | --- | --- |

通常対戦は対戦ごとに背景を選び、オンラインでは部屋・卓・ラウンドから双方共通の背景を決めます。
ヤマタノオロチがどちらかの席にいる場合は、固定背景より優先して龍になります。
チュートリアル本編はレッスンの `fieldTheme` を使用します。ピック画面は共通の宇宙背景を使用し、読みやすさのため暗い覆いを重ねます。

画像を差し替えるときは、画像の取り込みの規則（`AGENTS.md`）に従って新しいハッシュ付きの名前で取り込み、`BATTLE_FIELD_THEMES` の参照を更新してください。
カードが並ぶ中央（横の中央62%・縦の29〜70%）は静かにし、見せ場は左端と上の奥（上端から12%以上離す）に置きます。

彼岸花は作品内で特別な意味があるため、フィールドの雰囲気づくりだけを理由に追加しないでください。
