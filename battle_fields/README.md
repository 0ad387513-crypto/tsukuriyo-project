# 対戦フィールド背景

画像生成ツールで制作した、人物のいない和風ダークファンタジーのアニメ背景美術です。
画面は軽量な WebP を使用します。カード置き場の位置と枠線は従来のままです。
旧 SVG は保管用に残していますが、画面では使用しません。

神使フィールドは画像内の大鳥居の中心（横56%・縦36%）をフィールド中央へ合わせ、縦横比を保って拡大表示します。通常対戦とチュートリアル4で共通です。

| ファイル | 場所 | チュートリアル |
| --- | --- | --- |
| ninja.webp | 昼の忍者の隠れ里・修行場・手裏剣の的 | 弐「星戦の基本」 |
| beast.webp | 古木と動物に囲まれた人獣の森の郷 | 壱「カードの種類」 |
| samurai.webp | 鎧と金の襖が並ぶ侍の城内 | 参「守護と天力」 |
| dragon.webp | 左右の足が別々の列を進む龍の足跡と、爪痕のある燃える文明の残骸がある台地 | 通常対戦・ヤマタノオロチ対戦 |
| yokai.webp | 人魂と蝙蝠が浮かぶ妖怪の洞窟・沼（彼岸花は描かない） | 伍「応用ルール」 |
| shinshi.webp | 神社と聖堂の意匠を合わせた神使の神殿 | 肆「神技2の攻防」 |
| cosmic-pick.webp | 宇宙・地球・星雲の神秘的な背景 | 外伝「選別の心得」・創世決戦の選別の儀・星紡ぎ戦のパック選択 |

通常対戦は対戦ごとに背景を選び、オンラインでは部屋・卓・ラウンドから双方共通の背景を決めます。
ヤマタノオロチがどちらかの席にいる場合は、固定背景より優先して龍になります。
チュートリアル本編はレッスンの `fieldTheme` を使用します。ピック画面は共通の宇宙背景を使用し、読みやすさのため暗い覆いを重ねます。

生成に使った最終プロンプトは `generation_prompts.json` に保存しています。
画像を交換する場合は同名の WebP を差し替えてください。

彼岸花は作品内で特別な意味があるため、フィールドの雰囲気づくりだけを理由に追加しないでください。
