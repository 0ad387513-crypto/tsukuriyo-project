# 標準CPUの後攻計画・固定選択の修正と検証

2026-10-18／ローカルv1.15.525。コミット・PUSH・本番公開は行っていない。

## 変更

社の使用／温存を含む展開、除去・守護・手札差と疲労を考えた防御、選定・一般選択・数字宣言・誘・霊視・リロール・捨て札・進化元・効果再発動・守護・制約付き対象の判断を改善した。オンライン部屋のCPUへの捨て札依頼が実在しないクライアント待ちになる経路も修正。各経路の旧判断と新判断は [CPU判断の監査一覧](cpu-decision-audit-20261018.md) に一覧化している。

カード数値、後攻の追加ドロー・社・疲労のルール、ピックロジックは変更していない。初心者向けと人間の選択を標準CPUで上書きしない。ルール指定のランダムや一意の対象を恣意的な選択へ置き換えない。

## 最終比較の条件

- 4人組の全210通り×先後を反転した2反復×修正前後。各方式420大会・2,520星戦、最終比較は合計5,040星戦。各カミ504星戦／方式、先攻252・後攻252。
- v524とv525、固定198カード・10カミ、標準CPU、3ラウンドの実ドラフト／返還／深化／対戦／得点計算。同じ初期パック・席・シード・先後を対応。反復34〜35。対戦結果が後続ドラフトへ影響するため、後半まで完全同一デッキに固定した比較ではない。
- 四席ともCPUとして自動判断する。名目上の人間席の守護も各方式の実CPU守護判断へ委譲する共通アダプターを使用。この点を変えたため、以前のレポートの勝率との直接比較はしない。音声・画像・オンライン同期はこの対戦アダプターの対象外。
- 最終比較は全5,040星戦が正常終了し、停止・エラー・効果警告0。
- 防御のみの途中版5,040星戦は `candidate-defense/` に保存。リロール等を最終修正する前の広域監査版5,040星戦は `evaluation/` に保存し、最終成績へ混ぜていない。
- 最終の旧版2,520星戦はこの作業中に `evaluation/` で実行した同じ固定ソース・同じ共通アダプターの試合を再利用。最終新版2,520星戦はその後に新規実行した。前の会話の4,032試合等は再利用していない。途中版・試走を最終成績に加算していない。

## 検証と限界
