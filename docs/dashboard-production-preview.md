# カード枠と公開履歴の本番追従

- 共有ダッシュボードの現行カード枠は `/__production/` 経由で公開中の本番 `version.js`・ゲームHTMLのCSS/カード構造・外部CSS・`field_card_frames.js`・`field_card_art.js` を取得する。
- 表示はShadow DOM内。確認ページ側の数値用Georgia・手作りの寸法を使わず、本体のフォント・マナ/神攻力/戦闘力の寸法・配置・素材をそのまま利用する。拡大は全体のzoom。スタイルシートはカード間で共有。
- HTMLはtemplateの不活性な内容として解析する。ゲーム全体の画像を先読みせず、Vueやゲーム・Firebaseの起動処理も実行しない。独立した空のiframeでは公開済みの枠/切り抜きJSだけを読み込む。
- 本番のバージョンは60秒ごととページ復帰時に確認。変更担当者に関係なく、公開された更新を取得。読み込みに失敗したら黙って古い表示に代用しない。カード構造や公開関数の大きな変更では確認ページも検証する。
- H案はmain e410a6587e6feb471098cbe28624b3cb17ead3e3 (v1.15.538) のCSSと描画JSを保存。新しい本番の見た目へ置き換えない。
- 本番履歴も最新の公開済みJSONを取得し、担当者別の件数とボタンを表示。全担当者が既定。取得失敗時だけ同梱した履歴を明示して表示。未公開の共有ブランチの修正を本番履歴へ混ぜない。
- ローカルは `scripts/production_proxy.js`、共有用Netlifyは `_redirects` が同じ固定パスを提供する。送信は公開サイトへのGET/HEADだけで、認証・Cookieを転送しない。`main` への追加PUSHはこの対応では行っていない。
