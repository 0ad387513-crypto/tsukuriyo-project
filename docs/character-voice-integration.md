# キャラクターボイスをゲームへ反映する

現在の作成作業は `.release-worktree` で進んでいます。声・演技の選択はこれまでの試聴室で行ってください。ゲームへ登録する処理は外部APIを使わず、料金はかかりません。

1. 試聴室で声と採用テイクを選び、台詞を作成します。採用音声は `voices/cards/{台詞ID}.mp3` に保存されます。`previews`、`takes`、`library`、`_old` 内の音声はゲームの対象外です。
2. プロジェクト直下のターミナルで `npm run voices:prepare -- --root .release-worktree` を実行します。台本から `voices/cards/manifest.json` を生成し、音声の変更を知らせる `asset_hashes.js` も更新します。音声を追加・差し替えるたびに実行してください。正本の台本と作成済み台詞一覧は `tools/voice-script/card_voice_script.json` と `card_voice_lines.json` です。台本を変更した場合は、作成ツールの `cast` で一覧を作り直してから実行します。
3. http://localhost:8765/index.html を再読み込みし、カードの詳細画面のボイスの再生ボタンで確認します（確認用の一覧ページは 2026-10-14 に削除）。
4. 本番反映前は、音声直下の採用MP3、manifest、ハッシュ、今回のコードだけを他の作業者の最新コードへ統合します。ローカルの古い `index.html` 全体や未採用テイクを本番へコピーしないでください。現在は本番未反映です。

別のチェックアウトで音声を作成するときは、そのディレクトリで `npm run voices:prepare` を実行します。ルートには作成中の音声を複製していません。

カミのボイスは従来の `voices/{カミ番号}/{台詞キー}.mp3` と `voices/manifest.json` を使います。採用・差し替え後、そのチェックアウトで `node scripts/generate_voices_elevenlabs.js manifest` と `npm run assets:hash` を実行します。神技・エモート・勝利台詞・チュートリアルの既存の再生タイミングは維持しています。

## 再生のルール

- レガシー：場に出た時に召喚、攻撃の矢印を伸ばすドラッグが始まった時に攻撃、死亡処理に入った時に死亡。クリックだけでは攻撃ボイスは鳴らず、同じドラッグの攻撃確定時にも再生し直しません。CPUなどのドラッグを伴わない攻撃は宣言時に再生します。レリック・オラクル：使用時。通常版と進化版の対応は台本の `nos` を使います。
- オラクル発動・レガシー展開・レリック設置の中央画面を閉じてから、リロール確認、選定や対象選択へ進みます。CPUの自動解決は待機せず進めます。
- カミの神技・エモート・勝利台詞が優先です。カード音声がカミの台詞を遮りません。カード音声の終了を待って効果処理を止めることもありません。
- 音声は重ねずに順番に再生し、古くなった待機台詞を捨てます。大量破壊ではすべての死亡台詞を読み上げ続けません。設定画面の既存「ボイス」音量を使い、ミュート・非表示時のミュート・対戦終了・画面移動・Undoで停止します。再生中だけBGMが55%になります。
- 未作成の音声、再生拒否、読み込み失敗は無音で進みます。起動時に全音声をダウンロードしません。
- 同じ台詞IDの複数話者は順番に再生します。全員分が揃うまでは部分登録しません。
- 掛け合いは台本の `rival`（敵同士）/ `ally`（味方同士）、登場人物のカード番号、両方の完成音声が一致する場合に登録します。召喚時に該当する相手が場にいれば、通常の召喚台詞に代わって会話します。同じ組み合わせの会話は一対戦に一度です。
- オンラインでは既存の発動演出・攻撃通知・墓地/崩壊への移動を受け取って再生します。再接続時の過去通知や初回盤面は読み上げません。盤面全体を一度に受信する特殊効果では会話の判定・再生タイミングが操作側と完全一致するとは限りません。発動演出を公開しないトークンの召喚、途中参加の観戦者への死亡台詞は今回追加していません。

## 確認

`npm test` に音声一覧、通常版/進化版、掛け合いの相手判定、順番再生、ミュート、再生拒否、読み込み失敗、待機台詞の破棄の検証を含めています。音声・台本の作成作業中にハッシュの検証が失敗した場合は、作成が一区切りついてから再度 `voices:prepare` を実行してください。
